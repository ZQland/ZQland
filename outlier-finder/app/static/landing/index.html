Questions

Setup, data and the limits of the numbers.

Do I need API keys to try it?

No. Without keys the app fills each platform with made-up videos, so you can click through every page first.

Is scraping TikTok and Instagram allowed?

Not by their terms. It is common for personal research, but set Instagram to the official API and TikTok off to stay inside the rules.

Where do the video files go?

They are deleted after the analysis. About 8 sampled frames stay on the video’s page.

Which Claude model writes the breakdown?

Claude Opus 5.5, one call per video, with its answer checked against a fixed schema.

How does Outlier Finder estimate followers gained?

It is an estimate. No platform shares it for other people’s videos, so the app compares daily follower snapshots around each post.

Can Outlier Finder run on a schedule?

Yes. A daily refresh from cron adds new posts and the follower snapshots the estimates need.
